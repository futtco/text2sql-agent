# 实验证据

这个目录存放全部原始运行记录，根目录只保留代码与说明文件。

| 文件 | 内容 |
|---|---|
| `trace_*.jsonl` | 逐轮轨迹：每一步模型说了什么、提出哪句 SQL、工具返回了什么 |
| `log_*.txt` | 批量评测的完整控制台输出（含每道题的判定） |
| `runs_summary.jsonl` | 每次运行的汇总指标，共 99 条，记录模型与全部实验开关 |

文件按实验前缀区分（如 `trace_ra_` 是实验十一、`trace_sc_` 是实验九）。
`demo.py` 会回放其中三道真实轨迹，`10_analyze.py` 用它们做分层与判分重放；
新跑实验产生的文件也会自动写入本目录。

只想了解项目结论，看仓库根目录的 `README.md` 即可，这里主要用于复现和核对数字。
